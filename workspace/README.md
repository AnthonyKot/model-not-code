# Workspace (local only)

Untracked scratch for the research step of each essay:

```text
workspace/<slug>/
  lectures.md      # notes on the cited lectures, in the writer's words, with NN-NN locators
  pages/           # pdftotext dumps of the cited book pages, named <key>-pNNN.txt
  pitches-draft.md # working pitches before they go to notes/pitches/<slug>.md
```

Only receipts (`corpus/<slug>/receipts.tsv`) and the essay itself leave this directory.
